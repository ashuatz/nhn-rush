# 리소스 적용 현황

아트 리소스(fbx)가 게임 프리팹/씬에 배선됐는지 추적하는 문서.
갱신 시점: 2026-08-05

적용 절차: Stage Command Center > 에셋 셋업 > "아트 모델 적용" (전체 셋업에도 포함됨).
재실행하면 기존 주입분을 지우고 다시 만들기 때문에 fbx를 교체하면 버튼만 다시 누르면 된다.

원칙: 코드는 모델 배선만 담당하고 **머티리얼은 건드리지 않는다** (임포트 상태 그대로, 구성은 아트 담당).
모델 크기는 렌더러 바운드 기준으로 자동 정규화(타워 높이 1.4~1.6, 병사 0.9, 슬롯 받침 발자국 1.1)하고
바닥을 지면에 맞춘다. 모델에 딸려 온 콜라이더는 슬롯 클릭을 방해하므로 제거한다.

## 적용됨

| 리소스 | 대상 | 방식 | 비고 |
|---|---|---|---|
| environment/archertower 01~03 | Tower_Archer 프리팹 | TierVisuals/Tier1~3, 레벨별 온오프 | Lv4는 3티어 재사용 + 12% 확대 |
| environment/barracktower 01~03 | Tower_Infantry 프리팹 | TierVisuals/Tier1~3, 레벨별 온오프 | diffuse 텍스처 누락 (roughness만 있음) |
| environment/magiciantower 01~03 | Tower_Mage 프리팹 | TierVisuals/Tier1~3, 레벨별 온오프 | |
| environment/cannontower 01~03 | Tower_Artillery 프리팹 | TierVisuals/Tier1~3, 레벨별 온오프 | |
| environment/towerbase | 씬 TowerSlot Visual | 슬롯 받침 모델 교체 | 씬 셋업 시 자동 교체 |
| character/soldier.fbx | Soldier 프리팹 | Visual 아래 Model 주입 (큐브 렌더러 오프) | **애니메이션 미셋업 - 정적 포즈로 이동함** |

기존 더미 큐브는 삭제하지 않고 비활성으로 남겨 둔다 (모델이 없으면 자동 폴백).

## 미적용

| 리소스 | 용도 후보 | 필요한 작업 |
|---|---|---|
| character/soldier_rig.fbx + Anim/Sword* | 병사 애니메이션 | Animator 컨트롤러 구성, Soldier 상태(대기/이동/공격/사망) 연결. Anim/미확정 폴더 정리 필요 |
| environment/terrain | 씬 바닥 (현재 큐브 Ground) | 씬 셋업의 Ground 교체 + 경로와 높이 정합 확인 |
| environment/stone 01~05 | 씬 데코 | 배치 규칙 결정 후 씬 셋업에 추가 |
| environment/treeA 01~05, treeB 01~05 | 씬 데코 | 배치 규칙 결정 후 씬 셋업에 추가 |
| environment/load_diffuse.png | 경로 타일(PathVisual) 텍스처 | 머티리얼 구성 (아트 담당) |

## 아트 리소스 자체가 없는 것 (더미 큐브 유지)

- 몬스터 9종 (보병/궁병/탱크/전투기/마법 4종/보스)
- 발사체 5종 (화살/마법탄/포탄/미사일/단검), 착탄 이펙트
- 선택 링 / 사거리 표시기
- 경로 시작/출구 마커

## 알려진 정합 이슈

- 슬롯 받침(towerbase) 높이가 기존 큐브(0.25)와 다를 수 있어 타워가 살짝 뜨거나 묻힐 수 있다.
  건설 높이는 TowerSlot.BuildPosition(+0.25 고정)이므로 눈에 띄면 이 값을 조정할 것.
- barracktower는 diffuse가 없어 머티리얼 구성 전까지 회색으로 보인다.
