# 연석(Curb) 경로 툴 사용법

돌 바닥 가장자리처럼 "길이가 정해지지 않은 띠"를 만드는 도구다.
경로를 그리면 조각 메시가 나인슬라이스처럼 반복되고, 양 끝은 캡 조각으로 마감된다.

## 구성

| 파일 | 역할 |
|---|---|
| `Assets/Scripts/Art/CurbPath.cs` | 경로 + 조각 설정 컴포넌트 |
| `Assets/Scripts/Art/CurbMeshBuilder.cs` | 배치/변형/병합 로직 |
| `Assets/Scripts/Art/CurbBuiltinProfile.cs` | FBX 없을 때 쓰는 임시 단면 |
| `Assets/Scripts/Editor/CurbBakeUtility.cs` | 프리뷰/베이크 처리 |
| `Assets/Scripts/Editor/CurbPathEditor.cs` | 인스펙터 + 씬 핸들 |
| `Assets/Scripts/Editor/CurbBakeWindow.cs` | `Rush > Curb Baker` 윈도우 |

## 기본 흐름

1. `Rush > Curb Baker` 를 열고 **새 경로 만들기**. `CurbPath` + `LineRenderer`가 붙은 오브젝트가 생긴다.
2. 씬에서 경로를 잡는다.
   - 노란 점 드래그: 이동
   - `Ctrl + 클릭`: 끝에 점 추가 (바닥 지오메트리에 스냅)
   - 점 위 빨간 점 클릭: 삭제
   - 인스펙터 **바닥에 스냅**: 모든 점을 아래쪽 바닥으로 내림
3. 인스펙터 `middle`에 조각 FBX 메시를 넣는다. 필요하면 `startCap` / `endCap`도.
4. **프리뷰 갱신** 으로 자식 `CurbMesh`가 생기고, 이후 편집은 바로 반영된다.
5. 마무리되면 **Bake**. `Assets/RushGame/Generated/Curb_<오브젝트명>.asset` 으로 메시가 저장된다.

프리뷰 메시는 저장되지 않는다. 씬을 닫기 전에 반드시 Bake 할 것.

## ProBuilder 조각 만들 때 규칙

- 조각 1개는 **진행 방향으로 1타일** 분량만 만든다. 반복은 툴이 한다.
- 기본 진행축은 **+Z**. X/Y로 뽑았으면 인스펙터 `forwardAxis`에서 바꾼다. 방향이 반대면 `flipForward`.
- 단면(좌우/높이)의 원점은 경로 위에 오게 잡는다. 어긋나면 `sectionOffset`으로 밀 수 있다.
- 진행축 방향 길이는 바운즈에서 자동 측정한다. 피벗 위치는 상관없다.
- 캡은 중간 조각과 단면이 같아야 이음매가 안 보인다.
- FBX는 **삼각형으로 내보낸다**. 쿼드 서브메시는 건너뛰고 경고가 뜬다.
- `middle`을 비워두면 임시 사다리꼴 단면으로 프리뷰가 나온다. 축/오프셋 감 잡을 때 쓰면 된다.

## 주요 설정

| 항목 | 설명 |
|---|---|
| `sourceLine` | 지정하면 이 LineRenderer 포인트를 경로로 쓴다. 비우면 컴포넌트 자체 `points` 사용 |
| `closed` | 닫힌 고리. 캡을 넣지 않고 전체를 중간 조각으로 채운다 |
| `smoothIterations` | 코너 둥글리기(Chaikin). 0이면 꺾인 그대로 |
| `fitMode` | `StretchAll`: 중간 조각을 전부 균등하게 늘려 맞춤 / `StretchLast`: 원본 길이 유지, 마지막 하나만 조정 |
| `pieceScale` | 조각 전체 배율. 단면과 기준 길이에 함께 적용 |
| `middleLengthOverride` | 타일 기준 길이를 직접 지정(0이면 메시 바운즈) |
| `materials` | 비워두면 조각 FBX의 머티리얼을 자동으로 가져온다 |
| `maxPieces` | 조각 수 상한. 걸리면 경고가 뜨고 조각이 늘어난 상태가 된다 |

## 동작 방식 메모

- 경로를 아크 길이로 파라미터화하고, 조각의 각 버텍스를 진행축 위치에 맞춰 경로 위로 휘어 붙인다.
  코너에서 조각이 꺾이지 않고 휘기 때문에 틈이 생기지 않는다.
- 롤(기울기)은 항상 월드 업 기준이라 경사면에서도 연석이 서 있는 상태를 유지한다.
- 서브메시는 조각의 구성을 그대로 유지한다. 조각들 간 머티리얼 슬롯 구성이 같아야 한다.
