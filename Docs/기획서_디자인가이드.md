# 기획서 HTML 디자인 가이드

> 신규 기능 기획서 HTML을 작성할 때 이 규칙을 따른다.
> 목표: **흑백 베이스 · 심플 · 높은 가독성**. 색으로 정보를 구분하지 않고 형태(테두리/굵기/배지 모양)로 구분한다.

---

## 1. 기본 원칙

- **화이트 배경(`#ffffff`) + 검은 글씨(`#1a1a1a`)** 를 기본으로 한다.
- 보라/노랑/파랑 등 컬러 테마를 쓰지 않는다. 강조는 **검정·회색 그레이스케일 + 굵기/테두리**로만 표현한다.
- 정보 구분(가능/불가, 반영됨/안됨 등)은 색이 아니라 **형태로 구분**한다.
  - 예: 채워진 검정 배지 vs 흰 배경 + 검정 테두리 배지.
- 편집기(WYSIWYG)가 주입하는 인라인 스타일(`style="position: relative;"`, `border-image: …`, `color: rgb(…)`)은 **모두 제거**한다. 스타일은 `<style>` 블록의 클래스로만 관리한다.
- 텍스트 내용은 스타일 정리 시 **변경하지 않는다**. 구조/클래스만 손댄다.

## 2. 색상 팔레트 (`:root` 변수)

```css
:root{
  --bg:#ffffff; --card:#ffffff; --border:#d9d9d9; --accent:#000000; --accent-dark:#000000;
  --text:#1a1a1a; --sub:#666666; --warn-bg:#f5f5f5; --warn-border:#cccccc;
  --ok:#000000; --ng:#000000; --code-bg:#f5f5f5;
}
```

| 용도 | 값 |
|---|---|
| 본문 배경 | `#ffffff` |
| 본문 글씨 | `#1a1a1a` |
| 보조 글씨(캡션/설명) | `#666666` |
| 테두리 | `#d9d9d9` |
| 옅은 배경(박스/헤더/코드) | `#f5f5f5` ~ `#f2f2f2` |
| 강조(제목/검정 배지/버튼) | `#1a1a1a` / `#000000` |

**색은 이 그레이스케일 범위 밖으로 나가지 않는다.**

## 3. 핵심 컴포넌트 규칙

### 3.1 제목 (h1~h4)
- 모두 검정. `h2`는 아래 `border-bottom:2px solid #1a1a1a`로 구분.
- 섹션 번호(`.num`)도 검정 굵게. (보라색 번호 금지)

### 3.2 카드 / 표
- `.card`: 흰 배경 + `1px solid #d9d9d9` + `border-radius:8px`. 그림자는 최소화(또는 제거).
- `th`: 배경 `#f2f2f2`, 검정 글씨 굵게.
- 짝수 행: `#fafafa` (얼룩말 무늬로 가독성 확보).

### 3.3 배지 / 태그 (`.tag`) — ⚠ 중요
- **`.tag` 클래스를 절대 `<td>`에 직접 붙이지 않는다.** (`.tag`는 `display:inline-block`이라 셀 레이아웃이 깨지고 정렬이 틀어짐)
- 반드시 **셀은 `td.tagcell`, 배지는 안쪽 `<span class="tag …">`** 로 감싼다.

```html
<!-- ❌ 잘못된 방식 (정렬 깨짐, 여백 없음) -->
<td class="tag def">본 문서 3장</td>

<!-- ✅ 올바른 방식 (셀 중앙정렬 + 배지에 여백) -->
<td class="tagcell"><span class="tag def">본 문서 3장</span></td>
```

- `td.tagcell`은 **가운데 정렬 + 여백**을 갖는다.
- 배지는 알약형(둥근 pill). 의미 구분:
  - `.tag.ok` → 채워진 검정 배지(흰 글씨) = 긍정/반영됨
  - `.tag.ng` → 흰 배경 + 검정 테두리 = 부정/필요/안됨
  - `.tag.def` → 옅은 회색 배지 = 중립/정의 위치 안내

> **일반 규칙:** 표 셀 안에 배지·블록으로 감싼 요소가 들어가면 **셀을 가운데 정렬하고 여백을 준다.** 순수 텍스트 셀은 좌측 정렬 유지.

### 3.4 강조 박스 (warn / note)
- 컬러 배경 대신 **옅은 회색 배경 + 왼쪽 세로 바**로 구분:
  - `.warn`: 왼쪽 바 검정(`border-left:3px solid #1a1a1a`) — 예외/주의
  - `.note`: 왼쪽 바 회색(`border-left:3px solid #999`) — 참고/원칙
- 강조 텍스트(`b`)는 검정.

### 3.5 코드 (`code`, `pre`)
- 인라인 `code`: 옅은 회색 배경 + 검정 글씨, 고정폭 폰트.
- 코드 블록 `pre`: `#f5f5f5` 배경 + 검정 글씨 + `1px solid #e0e0e0`.
- 문법 강조는 색이 아니라 **굵기/기울임**으로:
  - `.cm`(주석) `#8a8a8a` 기울임 · `.kw`/`.fn` 검정 굵게 · `.str` `#555`

### 3.6 UI 목업 / 스토리보드
- 폰 화면(`.phone`)은 **흰 배경 + `1px solid #ccc` 테두리**. (어두운 보라 배경 금지)
- 말풍선/아이콘바: 옅은 회색(`#f2f2f2`).
- 예외: **토스트(`.excframe.toast`)만** 진회색(`#2b2b2b`) 배경 + 흰 글씨로 대비를 준다(실제 토스트 표현).
- 버튼: 주 버튼(`.b1`) = 검정 배경 흰 글씨 / 보조 버튼(`.b2`) = 회색 배경 검정 글씨.

### 3.7 플로우 / 단계 박스 (`.step`)
- 기본 `.step`: 회색 배경. `.step.action`: 검정 배경 흰 글씨. `.step.data`: 옅은 회색.

## 4. 흔한 실수 체크리스트

작성/정리 후 아래를 확인한다.

- [ ] `<td class="tag …">`처럼 배지 클래스를 셀에 직접 붙인 곳이 없는가 → `td.tagcell` + `span.tag`로
- [ ] `style="position: relative;"` 등 편집기 잡스타일이 남아있지 않은가
- [ ] `color: rgb(…)` / `border-image: …` 같은 인라인 컬러가 남아있지 않은가
- [ ] 블록/제목 태그가 엉뚱하게 다른 요소를 감싸고 있지 않은가 (예: `<h3>`가 표 전체를 감쌈)
- [ ] 빈 잔재 블록(예: `<div class="compare"></div>`)이 남아 여백을 만들지 않는가
- [ ] 대비가 낮은 회색 글씨(`#a99…` 등)를 흰 배경 위에 쓰지 않았는가 → `#666`/`#999`
- [ ] 표 안의 블록/배지 셀은 가운데 정렬 + 여백이 있는가

## 6. 클래스 빠른 참조

| 클래스 | 용도 |
|---|---|
| `.card` | 내용 묶는 흰 카드 |
| `.tagcell` + `.tag ok/ng/def` | 표 안 상태 배지(셀 중앙정렬+여백) |
| `.warn` / `.note` | 예외·주의 / 참고·원칙 박스 |
| `.flow` + `.step` (`.action`/`.data`) | 처리 흐름 다이어그램 |
| `.compare` + `.turnbox` + `.row`(`.sel`/`.variant`) | 좌우 비교 / 턴 목록 |
| `.storyboard` + `.frame` + `.phone` | UI 목업(폰 화면) |
| `.excframe`(`.modal`/`.toast`) | 모달/토스트 예시 |
| `.iconbar`, `.iconrow` | 아이콘 바 표현 |
| `details.card` + `summary` | 접이식 부록 |
