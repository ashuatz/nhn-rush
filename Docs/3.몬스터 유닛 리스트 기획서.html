몬스터 유닛 리스트 기획서

작성일: 2026-08-01 · 상위 문서: 2.타워디펜스 코어 룰 기획서(킹덤러쉬 베이스) §3
이 문서의 위치 — 2번 문서(코어 룰) §3에서 정의한 피해 유형(물리/마법/고정)·물리 방어·마법 방어 5단계 공통 규칙 위에, 몬스터를 지상형·공중형·마법·보스 4타입으로 분류하고 그 안에 총 9종(지상형 3 + 공중형 1 + 마법 4 + 보스 1)을 정의한다. 마법 4종은 지상형 3종·공중형 1종이 각각 마법의 힘으로 강화된 버전이다. 유닛마다 물리 방어와 마법 방어를 독립적으로 가진다.
1. 구성 원칙 2. 지상형 3종 3. 공중형 1종 4. 마법 4종 5. 보스 1종 6. 웨이브 구성 예시 7. 확장 원칙

1. 구성 원칙

4타입(지상형·공중형·마법·보스) 안에 총 9종을 둔다: 지상형 3종(보병·궁병·탱크) + 공중형 1종(전투기) + 마법 4종(위 4종 각각이 마법의 힘으로 강화된 버전) + 보스 1종.

2. 지상형 3종

유닛물리 방어마법 방어특징
보병낮음(Low)낮음(Low)표준 체력·속도로 걸어오는 기본 유닛. 웨이브 물량의 기본 구성원.
궁병낮음(Low)낮음(Low)사거리 내에 들어온 아군 보병(보병 타워 소환 유닛)을 원거리로 공격한다. 방치하면 아군 보병이 피해를 입으므로 빠르게 우선 처치하는 편이 유리하다.
탱크높음(High)보통(Medium)체력이 높고 이동이 느린 중장갑 유닛. 물리 방어가 높아 포병(장갑 관통) 대응이 효율적이다.

3. 공중형 1종

유닛물리 방어마법 방어특징
전투기보통(Medium)보통(Medium)경로 위를 날아서 빠르게 이동. 보병·포병 공격 불가 — 궁병·마도로만 요격 가능(2번 문서 §3.3).

4. 마법 4종

지상형 3종·공중형 1종이 각각 마법의 힘으로 강화된 버전이다. 새로운 행동을 하나씩 더해 챕터 후반부 긴장감을 만든다.

유닛물리 방어마법 방어특징
마법 보병보통(Medium)보통(Medium)보병의 마법 강화판. 체력 상승 + 소량 마법 재생.
마법 궁병보통(Medium)낮음(Low)궁병의 마법 강화판. 사거리·공격력 상승 — 아군 보병 피해가 더 커진다.
마법 탱크매우 높음(Great)보통(Medium)탱크의 마법 강화판. 물리 방어 최상급 + 이따금 마법 가속 돌진. 마도(타워)로 우회 공략 가능.
마법 전투기높음(High)높음(High)전투기의 마법 강화판. 물리·마법 방어 모두 상승 — 궁병·마도(타워) 둘 다 충분히 투자해야 처리된다.

5. 보스 1종

유닛물리 방어마법 방어특징
챕터 보스매우 높음(Great)매우 높음(Great)압도적 체력의 단일 유닛. 웨이브 최후반(2번 문서 §1.1 기준 10번째 웨이브) 단독 등장.

6. 웨이브 구성 예시

2번 문서 §1.1의 "1스테이지 10웨이브" 기준, 9종을 아래처럼 배치하는 예시다.

W1~2
보병 → W3~4
보병+궁병 → W5~6
탱크+전투기 → W7~8
마법 보병/궁병 → W9
마법 탱크/전투기 → W10
챕터 보스
초반(보병·궁병)에서 기본기를 익히고, 중반(탱크·전투기)에서 포병·궁병·마도(타워) 조합을 요구하며, 후반(마법)에서 같은 유닛의 마법 강화판으로 긴장감을 다시 끌어올린 뒤 보스로 마무리하는 구조다. 실제 챕터마다 순서·비율은 달라질 수 있다.

7. 확장 원칙

스탯 스케일링새 챕터마다 종을 늘리지 않고, 9종의 체력·공격력·속도·방어등급을 챕터 난이도만큼 상향한 버전을 우선 사용한다.
신규 종 추가 기준9종 조합만으로 표현 안 되는 완전히 새로운 행동 방식이 필요할 때만 추가를 검토한다.
⚠ 검토 대기. 9종 구성·스탯은 검토 후 추가 지시사항에 맞춰 조정한다.
